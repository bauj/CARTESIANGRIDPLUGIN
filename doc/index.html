Voxel plugin

3D algorithm Voxel 3D meshes a volume shape with an axis-aligned Cartesian grid of hexahedra (staircase voxels). Each cell belongs to the smallest solid containing its center (a point on a face counts as inside), so nested or overlapping solids (GDML World Volumes) work: the deepest volume wins.

Hypothesis Voxel Grid

  • Per axis X, Y, Z: Nb cells n (spacing = extent / n) or Step s (n = max(1, round(extent / s)), spacing adjusted so the grid covers the bounding box exactly). The extent is the tight bounding box of the main shape.
  • Cells outside all solids: Remove (default) or Keep. Kept cells are bound to the main shape, which must then be a compound; a warning gives their number.

Materials

Create solid groups on the geometry (in SHAPER GDML mode: Create material groups gives MAT_<material> groups), then tick Create all groups on geometry in the mesh dialog: one mesh group per material.

Python

mesh = smesh.Mesh(shape)
algo = mesh.Voxel()
hyp = algo.Grid(nbCells=[40, 40, 20])   # or step=2.5, keepOutsideCells=True
hyp.SetStep(2, 5.0)                     # axis 0=X, 1=Y, 2=Z
mesh.Compute()

Limits

  • The algorithm must be assigned to the main shape (all solids); no sub-meshes.
  • Every solid must be closed. Solids smaller than a cell may own no cell (warning).
  • Memory: about 760 bytes per hexahedron (nodes included) in the SMESH process; a 100x100x100 box (106 cells) computes in about 6.5 s on 12 threads.
